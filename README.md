# Proyecto de Construcción de Software - Universidad de Talca

Proyecto de Sistema de Gestión de base de datos y ventas. 

Este proyecto incluye funcionalidades de:
- Ver inventario
- Venta de stock
- Compra de stock
- Visualización de reportes
- Exportación de reportes en formato Excel y PDF
- Exportación de inventario en formato Excel
- Visualización de estadísticas financietas
- Administración de usuarios
- Envíos de reportes mediante correo con sistema de tokens integrado
- etc.
